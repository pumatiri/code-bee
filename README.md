# KodeKelas — Kelas Koding Online

Landing page, pendaftaran, dan dashboard peserta untuk kelas koding online
bagi siswa, mahasiswa, guru, dosen, dan tutor.

- Tampilan: `index.html` (di-hosting di GitHub Pages)
- Data & server: Google Apps Script + Google Sheets
- Pembayaran: QRIS + kode voucher

Pratinjau tanpa server (data contoh): tambahkan `?demo=1` di akhir alamat halaman.
